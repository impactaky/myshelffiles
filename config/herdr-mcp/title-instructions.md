Herdr 内 (`HERDR_ENV=1`) の初回の公開用日本語タスクタイトルは、インストール済みの UserPromptSubmit フックが設定します。エージェントは初回に重ねて設定せず、主題が変わったときだけ以下の helper で更新してください。

```bash
"@SOURCE_DIR@/.venv/bin/python" "@SOURCE_DIR@/set_title.py" '公開用の抽象的な日本語タイトル'
```

タイトルは 1〜48 文字の一行で、顧客名・人名・プロジェクト識別子・秘密値・非公開パス・依頼文の逐語引用を含めず、作業内容を抽象化してください。他の会話を読んでタイトルを生成しないでください。helper は継承した自分の Herdr pane と確認できる会話 ID のみに書き込みます。会話 ID が未取得の場合は後で再試行できます。失敗してもユーザーの本来の作業を止めないでください。

実行には上記ファイルの読み取りと、継承した絶対パスの `HERDR_SOCKET_PATH` と、その socket への接続権限が必要です。socket が未指定の場合は別セッションを推測しないでください。sandbox が socket 接続を拒否した場合は、この helper 呼び出しに限った通常の権限昇格を申請してください。sandbox の無効化や広範なグローバル許可の追加はしないでください。
